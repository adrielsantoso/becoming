# Open questions

Questions this project keeps open on purpose. Each entry ends by saying which of them it moved, and how. The numbers never change, so entries can refer to them.

1. If the birth order of spacetime atoms isn't physical, is becoming real, or only the finished order?
2. Does the limit already exist and draw the process toward it, or is it only where things would end up?
3. Is AI a new record tier, or just a powerful extension of symbols? Does it pass the closure test (does the record encode the machinery that reads it)?
4. Is there a fundamental level at all, or only real patterns at every scale? (from Ladyman)
5. What would measure the life-mind bridge, the way gene length and neuron count measure the tiers on either side?
6. Is there an Alpha Point, a first spacetime atom, or does Α go down forever?
